# 漫画サムネイルメーカー v2.0

YouTube動画や販売ページ用のサムネイル画像を簡単に作成できるChrome拡張機能です。背景画像と漫画の表紙画像を組み合わせて、ドロップシャドウ付きのプロフェッショナルなサムネイルを作成できます。

![Chrome Extension](https://img.shields.io/badge/Chrome-Extension-green?logo=googlechrome)
![Manifest V3](https://img.shields.io/badge/Manifest-V3-blue)
![License](https://img.shields.io/badge/License-MIT-yellow)

## ✨ 機能

- **サイドパネルUI** - ポップアップではなく広いサイドパネルで作業
- **背景のページ切り替え** - 10枠を4枚ずつ表示し、全巻・上下巻は常に表示
- **カスタム背景登録** - 見出し右側のコンパクトな登録欄から1〜10番に登録可能。2.0初回起動時に7番の背景を1番にも登録し、元の1番を復元用に保持
- **自動リサイズ** - アスペクト比を維持して最適なサイズに調整
- **ドロップシャドウ** - 濃いめの影で浮遊感を演出
- **全巻・上下巻モード** - 全巻特典(3枚)、上下巻(2枚)をそれぞれ最適な高画質サイズで自動並べ替え合成
- **Amazon書影取り込み** - 開いているAmazon.co.jpの商品ページから書影と書名を取得
- **第1〜3巻の一括取り込み** - 同じシリーズの書影を巻順で全巻モードの画像①〜③に配置
- **Amazonリンク作成** - 現在の商品からASINを取得し、保存済みのアフィリエイトタグでリンクを作成・自動コピー。手入力・コピーボタンにも対応
- **PNG保存** - 通常は「書名サムネイル.png」、全巻モードは「書名全巻サムネ.png」で保存

## 📦 インストール方法

1. このリポジトリをクローンまたはダウンロード
   ```bash
   git clone https://github.com/Tener2000/manga-thumbnail-maker.git
   ```

2. Chromeで `chrome://extensions/` を開く

3. 右上の「デベロッパーモード」をオンにする

4. 「パッケージ化されていない拡張機能を読み込む」をクリック

5. ダウンロードしたフォルダを選択

## 🎨 使い方

### 1. 背景画像を選択
プリセットグリッドから背景画像を選択します。
- 通常背景は「1〜4」「5〜8」「9〜10」を前へ・次へボタンで切り替え
- 全巻・上下巻のレイアウトは常に表示
- 初回起動時に7番の背景を1番にも登録（7番はそのまま保持）

### 2. カスタム背景を登録（オプション）
「背景画像を選択」の見出し右側で番号(1-10)を指定し、「背景登録」ボタンから独自の背景画像を登録できます。

### 3. 表紙画像をアップロード
Amazon.co.jpの商品ページで拡張機能アイコンを押し、「開いている商品の書影を取り込む」を押します。手動の場合は「表紙画像をアップロード」から選択できます。全巻モードでは「Amazonから第1〜3巻をまとめて取り込む」で同じシリーズの3枚を巻順に配置します。

### 4. プレビュー確認
背景の上に表紙画像がセンター配置され、ドロップシャドウが適用された状態をプレビューできます。

### 5. 画像を保存
プレビュー直下の「💾 PNG画像として保存」ボタンから保存します。「保存する書名」は編集でき、通常は`書名サムネイル.png`、全巻モードでは`書名全巻サムネ.png`になります。

### 6. Amazonリンクを作成
アフィリエイトタグを入力し、「開いている商品からリンク作成」を押すと、ASINを取得してリンクを作成し、自動でクリップボードにコピーします。タグは次回用に保存されます。自動コピーに失敗した場合は、既存のコピーボタンからコピーしてください。

## 📁 ファイル構成

```
漫画サムネイルメーカー/
├── manifest.json          # 拡張機能の設定
├── sidepanel.html         # サイドパネルUI
├── sidepanel.css          # スタイルシート
├── sidepanel.js           # メインロジック
├── background.js          # バックグラウンドスクリプト
├── backgrounds/           # 背景画像プリセット
│   ├── bg1.png           # パープル〜ピンク
│   ├── bg2.png           # ブルー〜シアン
│   ├── bg3.png           # オレンジ〜イエロー
│   ├── bg4.png           # レッド〜マゼンタ
│   ├── bg5.png           # グリーン〜ティール
│   ├── bg6.png           # ネイビー〜ライトブルー
│   ├── bg7.png           # 7番および2.0初回登録用の背景
│   ├── zenkan.png        # 全巻レイアウト
│   └── jogekan.png       # 上下巻レイアウト
└── icons/                 # 拡張機能アイコン
    ├── icon16.png
    ├── icon48.png
    ├── icon64.png
    └── icon128.png
```

## 🔧 技術仕様

| 項目 | 値 |
|------|-----|
| キャンバスサイズ(標準)     | 1280 x 720px (16:9) |
| キャンバスサイズ(全巻読込) | 1280 x 1280px (1:1) |
| キャンバスサイズ(上下巻)   | 1200 x 900px (4:3) |
| 余白 | 上下左右各5% |
| ドロップシャドウ | 35pxぼかし、18pxオフセット |
| 出力形式 | PNG |

## 🛠️ 使用技術

- **Chrome Extension Manifest V3**
- **Side Panel API**
- **Canvas API** - 画像合成
- **Chrome Storage API** - ユーザー設定保存
